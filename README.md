# Football Model animations

Interactive prototypes built from Frank Horn's Football Model 2026, for discussion.

- `index.html`: three animated patterns with decision questions (3rd Man concept, counter press, goal-kick pressing trap). Each scene is written as data (player and ball positions over time) and drawn the same way every time.
- `card.html`: Holding Midfielder position card, printable on A4, with section references to the model.

Player positions are illustrative. The football content belongs to Frank Horn's Football Model 2026.
