How these animations were made
  1. Start from the pattern as written in the Football Model, including its diagrams.
  2. Write the move down as data: where each player and the ball are at each moment. AI drafted this from the manual's text and diagrams.
  3. Draw the pitch, players, ball and measurements from that data. The same data always gives the same animation, so a coach changes a run or a pass by editing a number instead of redrawing a diagram.
